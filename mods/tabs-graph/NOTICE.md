# tabs-graph: origin and changes

**From:** Herdr's built-in `tabs` mod, version 0.1.13 (the tab bar).

**Licence:** Apache-2.0, in LICENSE-HERDR in this folder.

**Changed by Jochen Rau, 2026-11:**

- Panel toggles as mod commands (`tabs-graph.files`, `tabs-graph.changes`) so keys can open a side panel.
- Window icons are read from this folder (`mods/tabs-graph/`).
- Tabs keep their width: every tab has its close button (dim until hovered), and an agent's tab always has room for its status, so the bar doesn't shift as you switch tabs or an agent starts and stops.
